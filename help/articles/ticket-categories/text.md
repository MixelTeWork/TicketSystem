На странице мероприятия в разделе «Виды билетов» нажмите «Редактировать». Для двухдневного мероприятия категория объединяет варианты на первый, второй и оба дня. Каждый набор дней может быть выбран в категории только один раз.

Добавьте категорию, укажите её название и выберите нужные варианты. Для каждого задайте название, цену и при необходимости лимит. Нажмите «Сохранить». На однодневном мероприятии оформляется вариант первого дня.

## Какие настройки у вариантов отдельные

У каждого варианта свои цена, лимит и макет. Билет на оба дня не расходует количество вариантов первого и второго дней. При ручном оформлении сотрудник выбирает конкретный вид.

Предложенное название — начальное значение. Его можно изменить. Переименование категории не переписывает ранее заданные названия видов.

У сохранённого вида нельзя изменить набор дней. Для другого набора выберите соответствующий вариант. При смене вида конкретного билета его код, проходы и мерч сохраняются; доступны только ещё не использованные дни нового вида.
