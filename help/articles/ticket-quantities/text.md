В редакторе «Виды билетов» задайте значение поля «Лимит» для каждого нужного вида и сохраните изменения. Пустое поле означает отсутствие ограничения; ноль означает отсутствие свободных мест. Старые виды после обновления остаются без лимита, пока вы его не зададите.

Количество рассчитывается по всем неудалённым билетам этого вида. Использованный билет продолжает занимать место. Удаление билета освобождает его; смена вида переносит занятое место между видами. Вариант на оба дня имеет собственный лимит.

## Что увидит сотрудник

При ручном создании сверх лимита система предложит подтвердить превышение. «Добавить сверх лимита» продолжает оформление, «Отмена» сохраняет заполненные поля без создания билета. Для следующего билета подтверждение потребуется заново.

Предупреждение также возможно при переводе билета в другой заполненный вид. Обычное изменение данных билета в том же виде само по себе не добавляет занятое место.

Остаток может измениться, пока другой сотрудник оформляет билет. Окончательная проверка выполняется при сохранении. Лимит предупреждает о превышении при ручной работе, но не останавливает её без возможности подтверждения.
